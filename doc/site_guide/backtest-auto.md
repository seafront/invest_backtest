# Run Backtest — Auto 모드 (전략 비교)

주소: `/backtest?mode=auto`

종목 하나에 등록된 **모든 전략을 기본 파라미터로 최근 5년(오늘 기준)** 돌려 한 표에서 비교한다.
결과는 저장하지 않는다. 자세히 볼 전략만 "상세 보기"로 다시 돌려 저장한다.

## 입력

| 항목 | 의미 |
|---|---|
| Ticker | 비교할 종목. 목록은 캐시에 있는 종목이고, 아래에 종목명이 나온다 |
| Investment Mode | **거치식**(lump_sum): 첫날 원금을 한 번에 넣는다. **적립식**(dca): 매달 같은 금액을 넣는다 |
| Initial Capital / Monthly Contribution | 거치식 원금 또는 적립식 월 납입액. 통화별(원·달러)로 따로 기억한다 |

기간은 5년으로 고정이다. 파라미터를 바꿔 보려면 "상세 보기"에서 한다.

## 결과 머리말

- **`TICKER 종목명`**, **`시작일 ~ 끝일`**: 실제 데이터 구간이다. 상장이 늦어 5년이 안 되면
  노란 글씨로 "데이터가 …부터라 5년보다 짧습니다"가 뜬다.
- **투자원금**: 거치식은 초기 자본, 적립식은 5년 동안 넣은 금액 합계.
- **비교 구간 (3개월 / 6개월 / 1년 / 2년)**: 아래 "B&H 승률"과 "초과 중앙값"을 잴 때 쓰는 구간
  길이. 데이터 기간의 절반보다 긴 길이는 구간끼리 대부분 겹쳐서 고를 수 없다(회색).
- **"…개 구간 중 절반 넘게 B&H보다 수익이 높았던 전략: N / 14"**: 이 화면의 핵심 판정이다.
  괄호 안 "오늘 기준 총수익률로는 M / 14"는 참고용이다.

### 왜 총수익률이 아니라 롤링 비교인가

총수익률은 **끝 날짜에 크게 좌우된다.** 같은 TQQQ 5년이라도 끝 날짜만 바꾸면 B&H를 이긴 전략이
1/14에서 10/14까지 오간다. 그래서 같은 길이의 구간을 한 주씩 밀어 가며 전부 잘라 보고, 그중
몇 번이나 B&H보다 나았는지로 판정한다.

## 그래프

- 전략별 **누적 수익률**(%)을 주 단위로 겹쳐 그린다.
- **회색 점선**은 Buy & Hold(기준)다.
- 색 선은 표에서 체크한 전략이다. 처음엔 B&H 승률 상위 3개가 켜지고, 최대 4개까지 올릴 수 있다.
  색은 순위가 아니라 전략에 붙어서, 다른 전략을 켜고 꺼도 이미 켠 선의 색은 그대로다.
- 적립식이면 "그 시점까지 넣은 원금 대비" 수익률이다.
- 범례나 표의 줄에 마우스를 올리면 그 선이 강조된다.

## 표

열 제목을 누르면 그 기준으로 정렬한다(기본: B&H 승률). MDD만 작을수록 위로 간다.
B&H 줄은 기준이라 롤링 지표가 "—"이고, 정렬과 상관없이 아래로 간다.

| 열 | 의미 | 읽는 법 |
|---|---|---|
| 📈 | 그래프 표시 체크박스 | 체크하면 옆에 선 색이 나온다 |
| 전략 / 파라미터 | 전략 이름과 쓴 기본 파라미터 | 파라미터에 마우스를 올리면 설명이 나온다 |
| **▲ B&H** 배지 | 롤링 구간의 절반 넘게 B&H보다 수익이 높았음 | 이 화면의 "B&H를 이긴 전략" 표시 |
| **B&H 승률** | 선택한 길이로 잘라 본 구간 중 B&H보다 수익이 높았던 구간 비율 | 50% 초과면 대체로 B&H보다 낫다 |
| **초과 중앙값** | 그 구간들에서 B&H 대비 초과수익(%p)의 중앙값 | 이겼을 때 얼마나 이기고 졌을 때 얼마나 지는지의 가운데 값. 승률이 높아도 이게 작으면 차이가 미미하다 |
| **총수익률** | 오늘(마지막 거래일) 기준 누적 수익률 | 끝 날짜에 따라 크게 흔들린다. 참고용 |
| **CAGR** (적립식은 **IRR**) | 연환산 수익률. 적립식은 입금 시점을 반영한 내부수익률 | 기간이 다른 결과끼리 비교할 때 쓴다 |
| **Sharpe** | 위험(변동성) 한 단위당 초과수익. 연환산, 무위험수익률 2% | 1 이상이면 좋은 편. 수익이 같다면 높을수록 덜 흔들렸다 |
| **MDD** | 최대 낙폭. 고점에서 저점까지 가장 크게 빠진 비율 | 실제로 버틸 수 있는지 가늠하는 값 |
| **매매 승률** | 청산(SELL)한 매매 중 이익을 낸 비율 | **성과 지표가 아니다.** 작게 자주 벌고 한 번 크게 잃는 전략(평균회귀)이 높게 나온다 |
| **거래** | 청산(SELL) 횟수 | 많을수록 실전 비용(수수료·슬리피지)이 커진다. 느린 전략은 0~2회일 수 있다 |
| 상세 보기 | 그 전략을 같은 조건으로 다시 돌려 **저장**하고 결과 화면으로 간다 | 결과 화면에서 "← 전략 비교로 돌아가기"로 돌아오면 표가 그대로 남아 있다 |

표 아래 빨간 "실행 실패"는 오류가 난 전략 목록이다. 나머지 전략은 정상 비교된다.

## 읽을 때 주의

- **모두 기본 파라미터 결과**다. 순위는 파라미터에 따라 쉽게 바뀐다.
- 5년 한 구간이다. 그 5년이 상승장 위주였다면 현금 비중이 있는 전략은 B&H에 불리하다
  (사례: [../strategy/20260927.md](../strategy/20260927.md)).
- 비교 결과는 브라우저 탭 세션에만 남는다. 탭을 닫으면 다시 돌려야 한다.
