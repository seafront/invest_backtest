# Screener (조건 검색)

주소: `/screener`

**여러 조건을 동시에 만족하는 종목**을 찾는다. 백테스트를 하지 않고 **오늘(캐시의 마지막 거래일)의
상태**만 본다. 수익률 순위가 아니라 교집합을 구하는 화면이다.

## 입력

### 자주 쓰는 조합 (프리셋)

누르면 조건이 채워지고 바로 검색한다. 마우스를 올리면 근거가 나온다.

| 프리셋 | 의도 | 켜지는 조건 |
|---|---|---|
| 강한 종목 선별 | 수급이 들어오고 거래가 늘어난 종목 | 20일선 위, 거래대금 배율 ≥ 1, 외국인·기관 순매수 |
| 과열 제외 | 이미 급등한 종목을 걸러낸 뒤 본다 | 20일선 위, 외국인 순매수, 이격도 ≤ 10%, 5일 상승률 ≤ 8% |
| 조용한 매수 | 관심은 덜한데 수급이 쌓이는 종목 | 외국인·기관 순매수, 개인 쏠림 아님, 20일 수익률 ≥ -5%, 이격도 ≤ 8% |
| 눌림목 후보 | 60일선 위에서 20일선 아래로 눌린 구간 | 60일선 위, 외국인 순매수, 이격도 ≤ 0%, 52주 고가 대비 ≥ -25% |

### 대상

검색할 종목 묶음(예: KOSPI 200). "전체 캐시"는 DB에 시세가 있는 모든 종목이다.
최근 60거래일 미만 시세만 있는 종목은 빠진다.

### 켜고 끄는 조건

| 조건 | 판정 |
|---|---|
| 종가가 20일선 위 | 마지막 종가 > 20일 이동평균. 단기 추세가 살아 있다 |
| 종가가 60일선 위 | 마지막 종가 > 60일 이동평균. 중기 추세가 살아 있다 |
| 외국인 20일 순매수 `국내` | 최근 20거래일 외국인 순매수 **수량** 합계 > 0 |
| 기관 20일 순매수 `국내` | 최근 20거래일 기관 순매수 수량 합계 > 0 |
| 개인 쏠림 아님 `국내` | 최근 20거래일 개인 순매수 합계 ≤ 0. 개인이 몰려 사는 종목을 뺀다 |

`국내` 조건은 투자자별 수급 데이터가 있는 한국 종목에만 의미가 있다. 수급이 없는 종목은 0으로 봐서
이 조건을 켜면 통과하지 못한다.

### 기준값 (비우면 끔)

| 조건 | 계산 | 예시 |
|---|---|---|
| 거래대금 5일÷60일 (배 이상) | 최근 5일 평균 거래대금 ÷ 최근 60일 평균. 거래대금은 종가 × 거래량 근사치 | 1.5 = 최근 거래가 평소의 1.5배 |
| 20일선 이격도 (% 이하) | (종가 ÷ 20일 이동평균 − 1) × 100 | 낮게 잡을수록 과열을 걷어낸다. 0 이하 = 20일선 아래 |
| 5일 상승률 (% 이하) | 5거래일 전 종가 대비 수익률 | 급등 직후를 피한다 |
| 20일 수익률 (% 이상) | 20거래일 전 종가 대비 수익률 | 추세가 살아 있는 종목만 |
| 52주 고가 대비 (% 이상) | (종가 ÷ 최근 252거래일 최고 종가 − 1) × 100 | -25 = 고점에서 25% 안쪽 |

## 결과

### 조건별 통과 수 (깔때기)

머리말 **"N종목 → M종목"**은 대상 전체 수와 모든 조건을 통과한 수다.

| 열 | 의미 |
|---|---|
| 조건 이름, 기준값 | 켠 조건 |
| **단독 N종목** | 그 조건 **하나만** 걸었을 때 통과하는 수 |
| 막대 + 숫자 | 위에서부터 조건을 **차례로 더했을 때** 남는 수 |

**이 표가 이 화면의 핵심이다.** 결과가 9종목이라는 사실만으로는 조건을 어떻게 손봐야 할지 알 수 없다.
어느 조건이 199를 41로 줄였는지 보여야 그 조건을 풀지 조일지 정할 수 있다.
- 막대가 크게 줄어든 조건이 실제로 거른 조건이다.
- "단독" 수는 많은데 누적에서 크게 줄면, 앞선 조건과 함께 걸려서 줄어든 것이다.

### 결과 표

수급 데이터가 있으면 외국인 순매수 큰 순, 없으면 거래대금 배율 큰 순으로 최대 100종목을 보여 준다.

| 열 | 의미 |
|---|---|
| 종목 | 이름(누르면 Data Manager의 종목 화면), 아래 작은 글씨는 티커 |
| 업종 | KRX 업종(국내) 또는 industry |
| 종가 | 마지막 거래일 종가 |
| 이격도 | 20일선 이격도(%) |
| 거래대금 | 5일 ÷ 60일 거래대금 배율(×) |
| 5일, 20일 | 5일·20일 수익률 |
| 외국인, 기관 | 최근 20거래일 순매수 **수량**(주, "만" 단위). 금액이 아니다 |

## 읽을 때 주의

- 오늘의 상태만 본다. 조건을 통과했다고 앞으로 오른다는 뜻이 아니다. 조건 조합이 과거에 통했는지는
  백테스트로 따로 확인해야 한다.
- 결과는 캐시된 시세 기준이다. 시세·수급을 최근까지 받아 두지 않았으면 오래된 상태로 거른다.
