# 백테스트 결과 (상세 보기)

주소: `/results/:id`

저장된 백테스트 하나의 결과다. Auto 모드의 "상세 보기", Manual 모드 실행, Dashboard 기록에서 들어온다.
위에서 아래로 다음 순서로 나온다.

1. 머리말
2. 전략 파라미터
3. 파라미터 비교 (+ 추세 구간별 성과, 목표에 맞는 값 찾기)
4. 성과 지표
5. Equity Curve
6. 캔들 차트
7. Trade Log

## 1. 머리말

- **← 전략 비교로 돌아가기**: Auto 모드에서 왔을 때만 보인다. 비교표를 다시 계산하지 않고 복원한다.
- **`TICKER — strategy name`**, **`시작일 ~ 끝일`**
- **Lump Sum (거치식) Initial** 또는 **DCA (적립식) Monthly**: 투자 방식과 금액.

## 2. 전략 파라미터

이 결과를 만든 파라미터 값을 카드로 보여 준다.

| 표시 | 의미 |
|---|---|
| 큰 숫자 | 실제로 쓴 값 |
| 설명 | 파라미터가 무엇을 조절하는지 |
| 기본값 · 범위 | 전략의 기본값과 허용 최소–최대 |
| **기본값에서 변경** (주황) | 기본값과 다른 값으로 돌렸다는 표시 |

## 3. 파라미터 비교

값을 바꿔 **같은 구간·같은 투자 방식**으로 다시 계산한다. 저장하지 않고, 마음에 드는 변형만 저장한다.
파라미터가 없는 전략(Buy & Hold)에는 나오지 않는다.

- **입력칸**: 원래 값과 다른 칸은 주황 테두리로 표시된다. 범위를 벗어나거나 이미 넣은 값이면 사유가 나온다.
- **비교에 추가 / 원래 값으로**: 변형은 최대 3개. 원래 결과와 합쳐 4개 선까지 비교한다.
- **비교 구간**: Auto 모드와 같은 롤링 구간 길이(3개월~2년).
- **그래프**: 원래 값·변형·B&H(회색 점선)의 누적 수익률. **배경 초록은 상승 구간, 빨강은 하락 구간**이다.
- **표**

| 열 | 의미 |
|---|---|
| 구분 | 원래 / 변형 1~3 / 기준(B&H) |
| 파라미터 | 그 줄의 값 |
| B&H 승률, 초과 중앙값 | Auto 모드와 같다 ([backtest-auto.md](backtest-auto.md)) |
| 총수익률, CAGR(IRR), Sharpe, MDD, 거래 | Auto 모드와 같다 |
| 저장 / 삭제 | 변형을 정식 백테스트로 저장해 그 결과 화면으로 가거나, 변형을 지운다 |

같은 데이터로 고른 값은 실제보다 좋아 보이기 쉽다. 주변 값에서도 결과가 비슷한지 함께 봐야 한다.

### 3-1. 추세 구간별 성과

5년 합계만 보면 **어느 국면에서 벌고 잃었는지**가 묻힌다. 이 표는 기간을 상승·하락 구간으로 나눠
구간마다 성과를 보여 준다.

- **구간 나누는 법**: B&H가 고점·저점에서 임계값(%) 넘게 되돌린 곳을 전환점으로 본다.
  임계값은 종목 변동성에 비례한다(연 변동성 × 0.5, 10~40%). TQQQ는 약 32%, SPY는 10%다.
- **전환점은 지나고 나서야 확정된다.** 과거를 설명하는 구분이지 매매 신호가 아니다.

| 표시 | 의미 |
|---|---|
| ▲ 상승 / ▼ 하락 / – 횡보 | 구간 종류와 기간(개월), 길이(주). 횡보는 끝의 미완성 구간에만 나온다 |
| B&H 열 | 그 구간 B&H 수익률 |
| 전략 열의 값 | 그 구간 전략 수익률 |
| 괄호 (±%p) | 같은 구간 B&H 대비 차이 |
| **첫 매매 전** | 아직 한 번도 사지 않은 구간. 0%지만 방어한 게 아니라 **들어가지 않은 것**이라 비교하지 않는다 |
| **\*** | 구간 도중에 첫 매매가 있었다 |
| **상승 구간 포착률** | 상승 구간에서 B&H 상승분 중 가져간 비율. **높을수록 추세를 잘 따라감** |
| **하락 구간 노출률** | 하락 구간에서 B&H 하락분 중 맞은 비율. **낮을수록 방어를 잘함** |

포착률·노출률은 로그 수익률 합의 비로 잰다(+100%와 -50%를 같은 크기로 보기 위해서).
첫 매매 이후 구간만 센다.

**읽는 법:** B&H를 이기려면 포착률보다 노출률이 충분히 낮아야 한다. 상승장이 길고 하락이 얕은 종목
(SPY 등)은 포착률 1%를 잃는 비용이 노출률 1%를 줄이는 이득보다 크다.

### 3-2. 목표에 맞는 값 찾기 (파라미터 최적화)

파라미터 범위를 훑어 목표 점수가 좋은 값을 찾는다. 저장하지 않는다.

**과최적화를 막는 두 장치**
- **선택 구간 / 검증 구간**: 앞 60% 기간으로 값을 고르고, 뒤 40% 기간으로 확인한다.
  검증 구간은 고를 때 보지 않은 기간이다.
- **고원(plateau)**: 한 점만 튀는 값보다 주변 조합까지 고르게 좋은 값을 추천한다.

**목표**

| 목표 | 점수 | 추가 제약 |
|---|---|---|
| 꾸준히 B&H 이기기 | 1년 롤링 B&H 승률 + 초과수익 중앙값 × 0.1 | — |
| 위험 대비 수익 | Sharpe | 최대 낙폭 한도(선택) |
| 하락 방어 | 하락 구간 노출률(낮을수록 좋음) | 상승 포착률 50% 이상 |
| 추세 추종 | 상승 구간 포착률 | 하락 노출률 80% 이하 |
| 수익 극대화 | CAGR | — (과최적화에 가장 취약) |

**설정**
- **최소 진입 N회**: 선택 구간에서 적어도 N번은 포지션에 들어가야 후보로 인정한다.
  현금 상태에서 산 경우만 1회로 세고, 적립식의 월 자동 매수는 세지 않는다. 거의 매매하지 않아
  점수만 좋아 보이는 조합(MDD 0%, 노출 0%)을 걸러낸다. 느린 전략은 1~2회, 잦은 전략은 5~10회가 적당하다.
- **최대 낙폭 한도 %**: "위험 대비 수익"에서만 나온다. 이보다 MDD가 큰 조합은 추천에서 뺀다.
- **진행 표시**: "조합 done/total 계산 중". 조합이 많으면 격자 전체 대신 무작위로 뽑고 상위 근처를 정밀 탐색한다.

**결과**

| 표시 | 의미 |
|---|---|
| ★ 안정 추천 | 고원 점수 1위. 주변 조합까지 고르게 좋은 값 |
| ▲ 최고점 | 선택 구간 한 점의 최고 점수. 과최적화됐을 수 있다 |
| ○ 원래 값 | 지금 결과의 파라미터 |
| 목표 점수 선택 / 검증 | 두 구간 점수. 검증 점수가 선택 점수의 절반 넘게 떨어지면 빨간색 |
| CAGR (/ B&H) | 각 구간의 전략 CAGR과 같은 구간 B&H CAGR |
| MDD, 진입 | 각 구간의 최대 낙폭과 진입 횟수 |
| ⚠ 검증 구간에서 점수가 크게 떨어짐 | 선택 구간에 맞춰진 값일 가능성이 높다 |
| ⚠ 수익의 N%가 추세 구간 하나에서 나옴 | 60%를 넘으면 운 좋은 한 구간 덕일 수 있다 |
| 추천 제외: 사유 | 최소 진입·MDD 한도 등 제약을 어겨 추천에서 뺐다 |
| 비교에 추가 | 그 값을 위 "파라미터 비교"의 변형으로 넣는다 |

- **히트맵**: 파라미터 두 개(가로·세로)의 조합별 점수. 밝을수록 높다. 빗금 칸은 제약 위반, 빈 칸은
  평가하지 않은 조합이다. 파라미터가 3개 이상이면 칸마다 나머지 파라미터 중 가장 좋은 조합의 점수를 쓴다.
  밝은 칸이 넓게 뭉쳐 있으면 안정적인 값이고, 한 칸만 밝으면 우연일 가능성이 크다.
- **선 그래프**(파라미터 하나일 때): 값에 따른 선택 구간·고원·검증 점수.
- **고원 점수 상위 10개**: 고원 / 선택 / 검증 점수, CAGR 선택/검증, 진입, **집중도**(수익 중 가장 큰
  추세 구간 하나의 비중).

## 4. 성과 지표

| 지표 | 의미 |
|---|---|
| **Total Return** | 끝날 평가금액 ÷ 투자원금 − 1 |
| **CAGR** (적립식은 **IRR (연환산)**) | 거치식: 연평균 복리 수익률(일수 ÷ 365.25). 적립식: 입금 시점을 반영한 내부수익률. 원금 전부를 첫날 넣은 것으로 보는 CAGR과 다르다 |
| **Total Invested** | 적립식에서만. 기간 동안 넣은 원금 합계 |
| **Final Value** | 끝날 평가금액(현금 + 보유 주식) |
| **Sharpe Ratio** | (연환산 수익률 − 2%) ÷ 연환산 변동성. 일간 수익률 × √252로 연환산한다. 적립식은 입금액을 수익에서 빼고 계산한다(시간가중) |
| **Max Drawdown** | 평가금액이 직전 고점에서 가장 크게 빠진 비율 |
| **Win Rate** | 청산(SELL)한 매매 중 이익을 낸 비율. 매도가 없으면 0%(예: Buy & Hold, 느린 전략) |

## 5. Equity Curve

날짜별 **평가금액**(현금 + 주식) 곡선이다. 적립식이면 납입금이 쌓이면서 오르는 부분도 포함되므로,
수익률은 곡선 높이가 아니라 위 지표로 본다.

## 6. 캔들 차트

- 기간 동안의 일봉(시가·고가·저가·종가).
- **초록 ↑ (봉 아래)**: 매수 시점. **빨강 ↓ (봉 위)**: 매도 시점.
- 겹친 선은 전략이 쓰는 지표(이동평균, 밴드 등). 저장하지 않고 열 때마다 다시 계산한다.

## 7. Trade Log

| 열 | 의미 |
|---|---|
| # | 순번 |
| Date | 체결일 |
| Action | BUY / SELL. 적립식의 월 자동 매수도 BUY로 나온다 |
| Price | 체결가(그날 종가) |
| Shares | 수량 |
| P&L | SELL 줄만. 그 매매의 손익 |
